## English

### Reporting a Vulnerability
Please report security issues privately via email to [jj@jjtronics.com](mailto:jj@jjtronics.com). We will respond within 5 business days.

### Supported Versions
| Version | Supported |
| ------- | --------- |
| 4.x     | ✅ |
| < 4.0   | ❌ |

### Response Time
We aim to provide a fix within 30 days after confirming a vulnerability.

| ------- | --------- |
